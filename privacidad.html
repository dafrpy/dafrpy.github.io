Política de privacidad

Segundo cerebro · vigente desde el 17 de octubre de 2026

A quién aplica

Segundo cerebro es una aplicación personal con un único usuario, que es también su dueño y quien la opera. El inicio de sesión está limitado a una sola cuenta; nadie más puede usarla.

Qué datos usa

  • Cuenta de Google: el correo, para verificar que quien entra es el dueño.
  • Google Drive, Gmail y Google Calendar (solo lectura, y solo las carpetas, etiquetas y calendarios que el dueño elige): el contenido de archivos, correos y eventos, para indexarlo y poder buscarlo y responder preguntas sobre él.
  • Google Calendar (escritura): solo para crear un evento cuando el dueño lo pide desde un recordatorio.
  • Notas, audios y mensajes que el dueño manda al bot de Telegram.

Para qué los usa

Únicamente para darle al dueño las funciones de la aplicación: guardar, buscar, resumir y responder sobre su propia información. Los datos no se venden, no se usan para publicidad, no se comparten con terceros para sus propios fines y no se usan para entrenar modelos de inteligencia artificial generales.

Proveedores que procesan datos

Para generar respuestas, resúmenes, transcripciones y búsquedas semánticas, fragmentos del contenido se envían a proveedores de IA (Anthropic y, según la configuración, Voyage AI, OpenAI u OpenRouter) solo para procesar cada pedido del dueño, bajo sus condiciones de uso de API.

Dónde se guardan y cómo se protegen

Los datos se guardan en una base de datos en un servidor controlado por el dueño. Los tokens de acceso a Google y otras cuentas se guardan cifrados (AES-256-GCM). El acceso al panel requiere iniciar sesión con la cuenta autorizada.

Uso limitado de datos de Google

El uso y la transferencia de información recibida de las APIs de Google cumple con la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado (Limited Use).

Cómo revocar el acceso y borrar los datos

El acceso se puede revocar en cualquier momento desde myaccount.google.com/permissions o desconectando Google desde el panel de la aplicación, lo que borra los tokens guardados. El dueño puede borrar desde el panel cualquier elemento guardado y, como opera el servidor, también la base de datos completa.

Cambios

Si esta política cambia, se actualiza esta página con su nueva fecha.
